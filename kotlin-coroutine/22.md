# 22장 플로우 생명주기 함수

## onEach

플로우의 값을 하나씩 받음

람다식은 중단 함수

```kotlin
suspend fun main() {
    flowOf(1,2,3,4)
        .onEach { print(it) }
        .collect // 1234
}
```

#### 원소가 순서대로 처리된다

```kotlin
suspend fun main() {
    flowOf(1,2)
        .onEach { delay(1000) }
        .collect { println(it) }
}

// (1초 후)
// 1
// (1초 후)
// 2
```

## onStart

최종 연산이 호출될 때와 같이 플로우가 시작되는 경우에 호출됨

**주의!** 첫 번째 원소가 생성되는 걸 기다렸다가 호출되는 것이 아님

```kotlin
suspend fun main() {
    flowOf(1,2)
        .onEach { delay(1000) }
        .onStart { println("Before") }
        .collect { println(it) }
}

// Before
// (1초 후)
// 1
// (1초 후)
// 2
```

#### 원소를 내보낼 수도 있음

```kotlin
suspend fun main() {
    flowOf(1,2)
        .onEach { delay(1000) }
        .onStart { emit(0) } // 원소 내보내기
        .collect { println(it) }
}

// 0
// (1초 후)
// 1
// (1초 후)
// 2
```

## onCompletion

플로우가 완료되었을 때 호출됨 (잡히지 않는 예외가 발생했거나, 코루틴이 취소되었거나, 빌더가 끝났을 때)

```kotlin
suspend fun main() = coroutineScope {
    flowOf(1,2)
        .onEach { delay(1000) }
        .onCompletion { println("Completed") }
        .collect { println(it) }
}

// (1초 후)
// 1
// (1초 후)
// 2
// Compelted
```

```kotlin
suspend fun main() = coroutineScope {
    val job = launch {
        flowOf(1,2)
            .onEach { delay(1000) }
            .onCompletion { println("Completed") }
            .collect { println(it) }
    }
    delay(1100)
    job.cancel()
}

// (1초 후)
// 1
// (0.1초 후)
// Compelted
```

#### 프로그래스바를 보여주고 가리기

```kotlin
fun updateNews() {
    scope.launch {
        newsFlow()
            .onStart { showProgressBar() } // ProgressBar 보여주기
            .onCompletion { hideProgressBar() } // 작업 완료 후 Progressbar 가리기
            .collect { view.showNews(it) }
    }
}
```



## onEmpty

원소를 내보내기 전에 플로우가 완료되면 실행됨

기본값을 내보내기 위한 목적으로 사용될 수 있음

```kotlin
suspend fun main() = coroutineScope {
    flow<List<Int>> { delay(1000) }
        .onEmpty { emit(emptyList()) }
        .collect { println(it) }
}

// (1초 후)
// []
```

## catch

예외가 아래로 흐르지않도록 예외를 잡아 인자로 받고 정리

catch 함수의 윗부분에서 던진 예외에만 반응한다(아래로 흐르려는 걸 잡음)

```kotlin
class MyError: Throwable("My error")

val flow = flow {
    emit(1)
    emit(2)
    throw MyError()
}

suspend fun main() {
    flow.onEach { println("Got $it") }
        .catch { println("Caught $it") }
        .collect { println("Collected $it") }
}

// Got 1
// Collected 1
// Got 2
// Collected 2
// Caught MyError: My error
```

#### 예외를 잡아서 전파되는 것을 막는다

```kotlin
val flow = flow {
    emit("Message1")
    throw MyError()
}

suspend fun main() {
    flow.catch { emit("Error") }
        .collect { println("Collected $it") }
}

// Collected Message1
// Collected Error
```

#### 예외 처리 예시

```kotlin
fun updateNews() {
    scope.launch {
        newsFlow()
            .catch { view.handleError(it) }
            .onStart { showProgressBar() }
            .onCompletion { hideProgressBar() }
            .collect { view.showNews(it) }
    }
}
```

```kotlin
fun updateNews() {
    scope.launch {
        newsFlow()
            .catch {
                view.handleError(it)
                emit(emptyList()) // 기본값을 내보낼 수도 있음
            }
            .onStart { showProgressBar() }
            .onCompletion { hideProgressBar() }
            .collect { view.showNews(it) }
    }
}
```



## 잡히지 않은 예외

잡히지 않는 예외는 플로우를 즉시 취소하고 collect는 예외를 다시 던진다&#x20;

* 외부에서 try-catch로 예외를 잡을 수도 있다

```kotlin
val flow = flow {
    emit("Message1")
    throw MyError()
}

suspend fun main() {
    try {
        flow.collect { println("Coolected $it") } // 외부로 예외 던짐
    } catch (e: MyError) {
        println("Caught")
    }
}

// Collected Message1
// Caught
```

#### 최종 연산에서 발생한 예외는 catch 로 잡을 수 없다

```kotlin
val flow = flow {
    emit("Message1")
    emit("Message2")
}

suspend fun main() {
    flow.onStart { println("Before") }
        .catch { println("Caught $it") }
        .collect { throw MyError() } // 최종 연산에서 예외 발생, 잡지 못하고 외부로 던짐
}

// Before
// Exception in thread "..." MyError: My error
```

#### 예외가 발생할 것 같은 부분을 onEach 로 옮기고 collect 이전에 두기

최종 연산에서 예외가 발생할 것 같은 경우, 연산을 옮겨서 catch가 예외를 잡을 수 있도록 만들 수 있다

```kotlin
val flow = flow {
    emit("Message1")
    emit("Message2")
}

suspend fun main() {
    flow.onStart { println("Before") }
        .onEach { throw MyError() } // 연산 옮기기
        .catch { println("Caught $it") }
        .collect()
}

// Before
// Caught MyError: My error
```

## flowOn

플로우의 함수들은 기본적으로 collect가 호출되는 곳에서 컨텍스트를 얻어온다

```kotlin
fun usersFlow = flow {
    repeat(2) {
        val ctx = currentCoroutineContext()
        val name = ctx[CoroutineName]?.name
        emit("User$it in $name")
    }
}

suspend fun main() {
    val users = usersFlow()
    withContext(CoroutineName("Name1")) {
        users.collect { println(it) }
    }
    withContext(CoroutineName("Name2")) {
        users.collect { println(it) }
    }
}

// User0 in Name1
// User1 in Name1
// User0 in Name2
// User1 in Name2
```

#### flowOn으로 컨텍스트를 변경할 수 있다

단, 플로우의 윗부분에 있는 함수에서만 작동함

```kotlin
suspend fun present(place: String, message: String) {
    val ctx = coroutineContext
    val name = ctx[CoroutineName]?.name
    println("[$name] $message on $place")
}

fun messageFlow() = flow {
    present("flow builder", "Message")
    emit("Message")
}

suspend fun main() {
    val users = messageFlow()
    withContext(CoroutineName("Name1")) {
        users
            .flowOn(CoroutineName("Name3")) // 윗 부분의 컨텍스트 변경
            .onEach { present("onEach", it) }
            .onEach { present("onEach2", it) }
            .flowOn(CoroutineName("Name2"))    // 윗 부분들의 컨텍스트 변경
            .collect { present("collect", it) }
    }
}

// [Name3] Message on flow builder
// [Name2] Message on onEach
// [Name2] Message on onEach2
// [Name1] Message on collect
```

## launchIn

collect를 래핑하면 플로우를 다른 코루틴에서 처리할 수 있다

#### 플로우의 확장함수 - collect를 새로운 코루틴에서 시작할 수 있다

```kotlin
fun <T> Flow<T>.launchIn(scope: CoroutineScope): Job = 
    scope.launch { collect() }
```

#### 별도의 코루틴에서 플로우를 시작하기 위해 주로 사용

```kotlin
suspend fun main() = coroutineScope {
    flowOf("User1", "User2")
        .onStart { println("Users:") }
        .onEach { println(it) }
        .launchIn(this)
}

// Users:
// User1
// User2
```
